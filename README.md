# 🌐 Developer Portfolio

A modern, responsive personal developer portfolio website showcasing full-stack projects, architecture control flow diagrams, technical skills, achievements, and background experience.

🚀 **Live Portfolio:** [https://mahak1210-portfolio.vercel.app/](https://mahak1210-portfolio.vercel.app/)

---

## ✨ Features

- 💻 **Project Showcase:** Detailed breakdowns of full-stack web applications, microservices architecture, and live video demonstrations.
- 📐 **System Control Flow Diagrams:** Interactive flowchart diagrams showing authentication, routing, event queues, and database persistence.
- 🛠️ **Tech Stack & Skills:** Comprehensive overview of programming languages, frameworks, developer tools, and databases.
- 📜 **Resume & Experience:** Quick access to professional background, education, and coding platform profiles.
- 📱 **Responsive Design:** Modern UI optimized for desktop, tablet, and mobile viewing.

---

## 🛠️ Built With

- **Frontend:** React, Vite, Vanilla CSS, Lucide Icons
- **Deployment:** Vercel
